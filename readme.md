---

## 📝 Описание проекта

Проект содержит автоматизированные тесты для WordPress REST API с интеграционными проверками базы данных MySQL.

**Основная цель:** убедиться, что операции через API (создание, редактирование, удаление) корректно отражаются в базе данных.

### Покрытие тест-кейсами:
* ✅ **TC-001-003:** Позитивные тесты для постов (CRUD)
* ✅ **TC-004-006:** Негативные тесты для постов (Security, Validation)
* ✅ **TC-007-009:** Позитивные тесты для комментариев (CRUD)
* ✅ **TC-010-012:** Негативные тесты для комментариев (Authorization, Constraints)

**📝 Всего:** 12 автоматизированных тест-кейсов. Подробные тест-кейсы доступны в Google Docs:
👉 [Ссылка на тест-кейсы D1](https://docs.google.com/document/d/1tYbzsVp6X8MvtrHhvblEYVrYl-lKY5YuPQkCtqpT5pc/mobilebasic)

## 🛠️ Технологии

| Технология            | Назначение                            |
|:----------------------|:--------------------------------------|
| **Python 3.10**       | Язык программирования                 |
